Classic Minesweeper

Support

Classic Minesweeper supports macOS 13 or later.

Controls

  • Left click: uncover a square
  • Right click: flag, question, or clear a square
  • Both mouse buttons or middle click: open around a revealed number
  • F2: start a new game

Game sizes

Choose Beginner, Intermediate, Expert, or a Custom board from the Game menu. Interface scale can be changed under Game → Window Size.

Contact

For bug reports, questions, or feature requests, open an issue in the public support tracker. Include your macOS version and the steps needed to reproduce the problem.
