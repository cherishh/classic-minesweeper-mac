# Sources and treatment

- `zh-Hans/01.png` embeds `local-tests/xhs-winmine98/output/xhs-01-cover.png` intact inside the required 2880 × 1800 Mac screenshot canvas.
- Failure, best-time, and open-menu states come from the three screenshots supplied on 2026-07-26.
- Expert, Intermediate, and Beginner windows come from the real AppKit app captures under `AppStore/screenshots/source/`.
- Marketing copy uses modern system typography and is never placed inside a simulated Windows 98 dialog.
- Program UI is cropped and composited only; its pixels, text, colors, and controls are not regenerated.
- The background uses the classic Windows desktop teal `#008080`, with navy, silver, white, and safety orange accents.
